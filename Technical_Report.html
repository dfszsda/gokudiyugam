Gokudiyugam Project Technical Report

Comprehensive Architecture and Implementation Details

1. Project Overview

Gokudiyugam is a specialized spiritual community application designed to provide devotees with seamless access to daily darshan, spiritual music (Kirtans), video discourses, and community updates. The application focuses on high-performance media delivery and a multilingual user experience.

2. Core Technology Stack

Frontend (UI/UX) Jetpack Compose with Material Design 3. This provides a modern, declarative, and highly responsive user interface.
Language Kotlin - Utilizing Coroutines and Flow for asynchronous operations and state management.
Backend Services Firebase Suite (Authentication, Firestore, Realtime Database, Cloud Messaging, App Check).
Media Storage Google Drive API (v3) - Integrated as a scalable and cost-effective cloud storage for high-quality media files.
AI & Machine Learning Google ML Kit & Gemini SDK - Used for intelligent multilingual translations (English to Gujarati/Hindi) and potential content analysis.
Media Playback Android Media3 (ExoPlayer) for background audio and Pierfrancesco Soffritti’s YouTube Player for video content.

3. System Architecture

The project follows the MVVM (Model-View-ViewModel) design pattern, ensuring a clean separation of concerns between the business logic and UI.

  • Model: Data classes represent users, kirtans, media items, and playlists.
  • View: Composable functions in Jetpack Compose handle the display and user interactions.
  • ViewModel: Manages state and interacts with repositories/services (e.g., DriveViewModel, KirtanViewModel).

Real-time Sync Strategy

The application uses a dual-database synchronization strategy. When media is uploaded via Google Drive, metadata is stored in both Firebase Firestore (for complex queries) and Firebase Realtime Database (for instant UI updates across all clients).

4. Key Feature Implementations

Feature Implementation Detail
Role-Based Access (RBAC) Users are assigned roles (Host, Sub-Host, Guest, Normal) via Firestore. This controls upload/delete permissions.
Background Audio Uses Media3 and MediaSession to allow users to listen to Kirtans while the app is in the background or screen is locked.
Google Drive Integration Direct integration with GoogleAccountCredential to upload files and generate public-reader URLs for playback.
Smart Translation Combines Google ML Kit (for natural translation) with a custom "Barakhadi" mapping (transliteration) as a fallback for religious terminology.
Push Notifications FCM (Firebase Cloud Messaging) topics are used to notify all users immediately when new Darshan or Kirtans are available.
Dynamic Theming Users can customize the app's primary background colors and toggle Dark Mode, persisted via SharedPreferences.

5. Security and Maintenance

  • Firebase App Check: Protects backend resources from unauthorized traffic.
  • Biometric Security: Provides an optional layer of security for administrative panels.
  • Auto-Cleanup: A logic in DriveViewModel periodically cleans up expired content based on timestamps.
  • ProGuard/R8: Enabled for release builds to minify code and optimize performance.

6. Conclusion

The Gokudiyugam app represents a robust integration of modern Android development tools. By leveraging cloud APIs like Google Drive alongside real-time databases, it achieves a scalable architecture capable of serving a global community with high-fidelity spiritual content.
